# sem-cara-de-ia

Kit gratuito do INEMA para medir oito sinais de site genérico em HTML/CSS local. Não determina autoria. O script independente fica em `skill/sem-cara-de-ia/scripts/checar.js`; a raiz só encaminha a execução.

Teste: `node --test`. Node.js >= 18, zero dependência, sem instalação de pacotes, sem API e sem acesso externo. Só URLs HTTP de localhost/127.0.0.1 são aceitas. Não criar guia nem traduções sem pedido. Preserve `PESQUISA-BIBLIOTECAS.md`.

## Self-learning

Quando corrigido, gravar a lição em uma linha no topo de `LESSONS.md`.
