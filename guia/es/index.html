Tu sitio creado con IA tiene cara de IA

Y el cliente lo nota en dos segundos: piensa que tu negocio también es genérico y se va antes de leer lo que haces. La prueba de la cara de IA muestra qué delata tu sitio y cómo corregirlo, sin perder lo que ya está listo.

En resumen

Quien crea sitios con IA suele recibir siempre la misma página: fondo morado y azul, tres cajitas iguales, emojis en lugar de íconos y frases como «revoluciona tu negocio». El visitante ya lo vio mil veces y asocia tu negocio con un modelo prefabricado. La prueba de la cara de IA es un kit gratis que lee tu página, busca estas señales, le da una nota de 0 a 10 y te dice cómo corregir cada una. Funciona en tu computadora, sin cuenta y sin enviar nada a ningún sitio. Incluye una skill para que Claude Code rehaga el diseño por ti y una lista de bibliotecas abiertas verificadas.

Las señales

Lo que delata tu sitio web

Cada señal por sí sola no es un problema. Juntas, hacen que el sitio parezca salido del mismo molde que otros mil. La prueba mide ocho, cada una con una regla clara.

1

Degradado de morado → azul

El fondo que va del morado al azul es el «cielo» predeterminado de las páginas generadas.

Cámbialo por un color de marca, un fondo liso o una foto real.

2

Una sola fuente

La misma tipografía neutra en títulos y textos borra la personalidad.

Cámbialo por un título con personalidad y un texto fácil de leer; como máximo dos.

3

Emoji en lugar de ícono

🚀 ✨ 💡 en los títulos parecen adornos automáticos y cambian de un dispositivo a otro.

Cámbialo por íconos de trazo de un solo conjunto, o ninguno.

4

Tres tarjetas iguales

Tres cajas con sombra y esquinas redondeadas dan el mismo peso a todo.

Cámbialo por un elemento destacado, una lista numerada o una foto del trabajo.

5

Parte superior centrada con dos botones

Título en el centro y «Comienza ahora» + «Más información»: sirve para cualquier empresa.

Cámbialo por para quién es, qué obtiene la persona y un botón con el siguiente paso.

6

Frases cliché

«Revoluciona», «potencia», «soluciones innovadoras»: promesas vagas en lugar de información.

Cámbialo por plazo, precio, lugar y quién atiende.

7

Contraste bajo

El texto gris claro sobre blanco cansa y desaparece en la pantalla del celular.

Cámbialo por un texto más oscuro, con un contraste de al menos 4,5 a 1.

8

El mismo rincón en todo

El botón, la caja, la foto y la franja tienen los mismos bordes redondeados: nada tiene una función propia.

Cámbialo por esquinas con intención: pequeñas en campos, medianas en tarjetas.

Por qué esto importa ahora: en nuestro radar de lo que está de moda, un video sobre cómo hacer que el sitio creado con Claude Code no parezca hecho con IA tuvo 219 veces lo normal del propio canal, 263 mil visualizaciones en 5 días (ronda del 12/11/2026). Mucha gente crea sitios con IA y está cansada de ver siempre el mismo aspecto.

Palabras que aparecen aquí

Degradado
fondo que pasa gradualmente de un color a otro.
Fuente
el diseño de las letras. «Dos tipografías» = una para los títulos y otra para el texto.
Tarjeta
caja con borde o sombra que agrupa un título y un texto.
Parte superior (hero)
la primera parte de la página, la que aparece antes de desplazarte.
Contraste
la diferencia de luminosidad entre el texto y el fondo. La regla de accesibilidad exige al menos 4,5 a 1.
Rayo
cuánto se redondea la esquina de una caja o un botón.
Skill
un archivo de instrucciones que enseña a Claude Code a realizar una tarea de principio a fin.

Cómo corregir

Elige una dirección y sigue hasta el final

Lo que quita el cara de IA no es cambiar un botón: es decidir cómo debe verse tu negocio y aplicarlo en todo. El kit trae cinco estilos listos, cada uno con un par de fuentes de Google Fonts, colores con el contraste ya medido, tamaño de las esquinas y aspecto de la parte superior de la página.

1. Ejecuta la prueba

Mira la calificación y qué señales tiene tu sitio. La prueba guarda en un archivo la lista de lo que hay que corregir. Cómo usar ↓

2. Elige una dirección

Una sola, según el estilo de tu negocio. Mezclar dos vuelve a darle aspecto de plantilla.

3. Deja que Claude Code lo rehaga

La skill del kit reescribe solo lo visual y los textos vagos. Cuando falta un dato tuyo (precio, plazo, ciudad), marca «PREENCHA» en vez de inventarlo.

Bibliotecas de UI

La biblioteca ayuda, pero no le quita la apariencia por sí solo

Las bibliotecas de componentes ofrecen botones, menús y formularios listos para usar, y funcionan bien con Claude Code. Pero la biblioteca más famosa, con el tema predeterminado, es justamente una de las que dan cara de IA. Instálala, aplica tu dirección visual y vuelve a ejecutar la prueba.

Parte técnica

El kit: para quien quiere probar su propio sitio web

De aquí para abajo está la parte técnica: descargar, ejecutar la prueba e instalar la skill. Tú no hace falta de esta parte para entender lo que está arriba.

Qué es

Una prueba local, con una regla explícita

La prueba mide señales de un sitio genérico. Esta no descubre quién hizo el sitio: una página hecha a mano también puede tener estas señales, y una calificación alta no garantiza que el sitio sea bueno.

Sin instalar nada

Un script en Node.js, sin dependencias, sin API y sin internet. Lee el HTML, los estilos de la página y los archivos CSS locales.

Entiende Tailwind

Lee las clases del atributo class (from-purple-500, rounded-2xl, text-gray-400) y encuentra las mismas señales en ellos.

Skill para Claude Code

Ejecuta la prueba, elige un estilo, reescribe el aspecto en una copia y vuelve a probar hasta obtener una nota de 8 o más.

Cómo funciona

Del sitio a la lista de correcciones

Página (archivo, carpeta o localhost)→ Lee HTML + CSS + clases→ 8 reglas con ponderación→ Nota de 0 a 10→ consertar.md→ Claude Code con la skill

La puntuación empieza en 10 y resta el peso de cada señal que se activa (1 o 1,5 puntos). Por debajo de 7, quien visita el sitio lo nota. Código de salida: 0 con una calificación de 7 o más, 1 por debajo de 7, 2 por error de entrada. Las reglas exactas están en referencias/sinais.md (en portugués).

Requisitos previos

Lo que necesitas

Node.js 18 o posterior

Comprueba con:

node --version

git

Para descargar el kit:

git clone https://github.com/inematds/sem-cara-de-ia
cd sem-cara-de-ia

El HTML de tu sitio

El archivo, la carpeta o el sitio en funcionamiento en http://localhost. En React/Vue, usa el HTML del build (p. ej.: dist/index.html).

Guía de uso · paso a paso

En 5 minutos

1

Ejecuta la prueba con el ejemplo

Para ver cómo es el resultado antes de probar tu sitio:

node checar.js exemplos/com-cara-de-ia   # puntuación 0 de 10
node checar.js exemplos/sem-cara         # puntuación 10 de 10
2

Ejecuta la prueba en tu sitio

Puede ser el archivo, la carpeta (lee el index.html) o el sitio funcionando en tu computadora:

node checar.js ~/meu-site/index.html
node checar.js ~/meu-site
node checar.js http://localhost:3000/
# otras opciones: --json (para automatización) · --sem-cor
3

Anota la lista de lo que debes corregir

El archivo queda listo para pegarlo en tu agente de código:

node checar.js ~/meu-site --md consertar.md
4

Instala la skill en Claude Code

La carpeta de la skill incluye el script; funciona por sí sola después de copiarla:

mkdir -p ~/.claude/skills
cp -r skill/sem-cara-de-ia ~/.claude/skills/
5

Pide que le quiten el cara de IA

Abre Claude Code en la carpeta de tu sitio (preferiblemente en una rama o una copia) y escribe:

quita la cara de IA de mi sitio. Dirección: artesanal editorial.
# sin indicar la dirección, la skill elige según el tipo de negocio y explica por qué

Ejecuta la prueba, muestra la puntuación, reescribe el aspecto visual y los textos genéricos, marca [PREENCHA: …] donde falta un dato tuyo y vuelve a ejecutar la prueba hasta obtener una nota de 8 o más.

6

Comprueba en el navegador

La prueba no ejecuta JavaScript, no analiza imágenes ni descarga CSS externo. Abre el resultado en el celular y en la computadora antes de publicarlo.

node --test   # las pruebas del propio kit
