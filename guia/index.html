Seu site feito com IA tem cara de IA

E o cliente percebe em dois segundos: acha que o seu negócio também é genérico e sai antes de ler o que você faz. O teste da cara de IA mostra o que denuncia o seu site e como corrigir, sem perder o que já está pronto.

Em resumo

Quem faz site com IA costuma receber a mesma página: fundo roxo e azul, três caixinhas iguais, emoji no lugar de ícone e frases como "revolucione o seu negócio". O visitante já viu isso mil vezes e liga o seu negócio a um modelo pronto. O teste da cara de IA é um kit grátis que lê a sua página, procura esses sinais, dá uma nota de 0 a 10 e diz como corrigir cada um. Ele roda no seu computador, sem conta e sem enviar nada para fora. Vem com uma skill para o Claude Code refazer o visual por você e com uma lista de bibliotecas abertas conferidas.

Os sinais

O que denuncia o seu site

Cada sinal sozinho não é crime. Juntos, eles fazem o site parecer saído da mesma fôrma que mil outros. O teste mede oito, cada um com uma regra clara.

1

Gradiente roxo → azul

O fundo que vai do roxo ao azul é o "céu" padrão das páginas geradas.

Troque por uma cor da marca, fundo liso ou foto real.

2

Uma fonte só

A mesma letra neutra em títulos e textos apaga a personalidade.

Troque por um título com personalidade e um texto fácil de ler; no máximo duas.

3

Emoji no lugar de ícone

🚀 ✨ 💡 nos títulos parecem enfeite automático e mudam de aparelho para aparelho.

Troque por ícones de traço de um conjunto só, ou nenhum.

4

Três cards iguais

Três caixas com sombra e canto arredondado dão o mesmo peso a tudo.

Troque por um item em destaque, uma lista numerada ou foto do trabalho.

5

Topo centralizado com dois botões

Título no meio e "Comece agora" + "Saiba mais": serve para qualquer empresa.

Troque por para quem é, o que a pessoa ganha e um botão com o próximo passo.

6

Frases clichê

"Revolucione", "potencialize", "soluções inovadoras": promessa vaga no lugar da informação.

Troque por prazo, preço, lugar e quem atende.

7

Contraste baixo

Texto cinza claro sobre branco cansa e some na tela do celular.

Troque por um texto mais escuro, com contraste de pelo menos 4,5 para 1.

8

O mesmo canto em tudo

Botão, caixa, foto e faixa arredondados igual: nada tem função própria.

Troque por cantos com intenção: pequenos em campos, médios em cartões.

Por que isso importa agora: no nosso radar do que bomba, um vídeo sobre deixar o site feito com o Claude Code sem cara de IA fez 219 vezes o normal do próprio canal, 263 mil visualizações em 5 dias (rodada de 12/11/2026). Muita gente faz site com IA e está cansada de ver a mesma cara em todos.

Antes e depois

O mesmo negócio, de 0 a 10

Uma marcenaria de exemplo (fictícia), com o mesmo conteúdo nas duas versões. A diferença é a direção visual.

Como corrigir

Escolha uma direção e siga até o fim

O que tira a cara de IA não é trocar um botão: é decidir como o seu negócio deve parecer e aplicar isso em tudo. O kit traz cinco direções prontas, cada uma com par de fontes do Google Fonts, cores com o contraste já medido, tamanho dos cantos e como fica o topo da página.

1. Rode o teste

Veja a nota e quais sinais o seu site tem. O teste grava a lista do que corrigir num arquivo. Como usar ↓

2. Escolha uma direção

Uma só, pelo jeito do seu negócio. Misturar duas volta a dar cara de modelo pronto.

3. Deixe o Claude Code refazer

A skill do kit reescreve só o visual e os textos vagos. Onde falta um fato seu (preço, prazo, cidade), ela marca "PREENCHA" em vez de inventar.

Bibliotecas de UI

Biblioteca ajuda, mas não tira a cara sozinha

Bibliotecas de componentes dão botões, menus e formulários prontos e funcionam bem com o Claude Code. Mas a biblioteca mais famosa, com o tema padrão, é justamente uma das caras de IA. Instale, aplique a sua direção visual e rode o teste de novo.

Parte técnica

O kit: para quem quer testar o próprio site

Daqui para baixo é a parte técnica: baixar, rodar o teste e instalar a skill. Você não precisa desta parte para entender o que está acima.

O que é

Um teste local, com regra explícita

O teste mede sinais de site genérico. Ele não descobre quem fez o site: uma página feita à mão também pode ter esses sinais, e uma nota alta não garante um site bom.

Sem instalar pacotes

Um script em Node.js, sem dependências, sem API e sem internet. Lê o HTML, os estilos da página e os arquivos CSS locais.

Entende Tailwind

Lê as classes do atributo class (from-purple-500, rounded-2xl, text-gray-400) e acha os mesmos sinais nelas.

Skill para o Claude Code

Roda o teste, escolhe uma direção, reescreve o visual numa cópia e testa de novo até a nota 8 ou mais.

Como funciona

Do site à lista de correções

Página (arquivo, pasta ou localhost)→ Lê HTML + CSS + classes→ 8 regras com peso→ Nota de 0 a 10→ consertar.md→ Claude Code com a skill

A nota começa em 10 e perde o peso de cada sinal que dispara (1 ou 1,5 ponto). Abaixo de 7, o visitante percebe. Código de saída: 0 com nota 7 ou mais, 1 abaixo de 7, 2 em erro de entrada. As regras exatas estão em referencias/sinais.md.

Pré-requisitos

O que você precisa

Node.js 18 ou mais novo

Confira com o comando abaixo. Se não tiver, baixe em nodejs.org (versão LTS) ou peça ao Claude Code para instalar.

node --version

git

Para baixar o kit:

git clone https://github.com/inematds/sem-cara-de-ia
cd sem-cara-de-ia

O HTML do seu site

O arquivo, a pasta, ou o site rodando em http://localhost. Em React/Vue, use o HTML do build (ex.: dist/index.html).

Guia de uso · passo a passo

Em 5 minutos

1

Rode no exemplo

Para ver como é a saída antes de testar o seu site:

node checar.js exemplos/com-cara-de-ia   # nota 0 de 10
node checar.js exemplos/sem-cara         # nota 10 de 10
2

Rode no seu site

Pode ser o arquivo, a pasta (ele lê o index.html) ou o site rodando no seu computador:

node checar.js ~/meu-site/index.html
node checar.js ~/meu-site
node checar.js http://localhost:3000/
# outras saídas: --json (para automação) · --sem-cor
3

Grave a lista do que corrigir

O arquivo sai pronto para colar no seu agente de código:

node checar.js ~/meu-site --md consertar.md
4

Instale a skill no Claude Code

A pasta da skill leva o script dentro; funciona sozinha depois de copiada:

mkdir -p ~/.claude/skills
cp -r skill/sem-cara-de-ia ~/.claude/skills/
5

Peça para tirar a cara de IA

Abra o Claude Code na pasta do seu site (de preferência num branch ou numa cópia) e escreva:

tira a cara de IA do meu site. Direção: artesanal editorial.
# sem dizer a direção, a skill escolhe pelo tipo de negócio e explica por quê

Ela roda o teste, mostra a nota, reescreve o visual e os textos genéricos, marca [PREENCHA: …] onde falta um fato seu e roda o teste de novo até a nota 8 ou mais.

6

Confira no navegador

O teste não executa JavaScript, não olha imagens e não baixa CSS de fora. Abra o resultado no celular e no computador antes de publicar.

node --test   # os testes do próprio kit
